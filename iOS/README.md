# EC20Mobile (iPhone 配套 App)

本目录包含适用于 iOS 16+ 的 iPhone 配套客户端源码，配合 Mac 端运行的 **EC20Companion** 蜂窝网关，实现 iPhone 与 Mac 上的 Quectel EC20 4G 模块局域网互联。

> 当前是实验性源码：尚未在 iPhone 真机完成构建和端到端验收。下列功能描述的是代码设计与实现状态，不代表已验证可在所有设备上使用。

---

## 1. 核心特性

- **局域网自动发现**：通过 Bonjour (`_ec20companion._tcp`) 自动发现局域网内的 Mac 网关。
- **安全加密通道**：
  - 基于 CryptoKit `Curve25519.KeyAgreement` (ECDH) 动态协商临时会话密钥；
  - 数据传输全程使用 `ChaCha20-Poly1305` AEAD 对称加密与防篡改鉴权；
  - 16 位一次性安全配对密钥（约 80 位熵，5 分钟有效，最多 5 次错误锁定），密钥不会明文上网传输。
  - 首次配对后，iPhone 私钥保存在本机 Keychain；断线后通过加密随机质询自动恢复会话，无需重复输入配对密钥。
- **信息 (SMS)**：
  - 微信式对话界面，支持长短信与 UCS2 中文；
  - 首次连接与重连执行全量同步，在线期间接收实时短信事件；协议保留增量同步令牌字段供后续优化；
  - 支持前台横幅通知、声音与主屏幕未读角标；
  - 多选批量删除会话与单条短信（双端一致性同步）。
- **电话与最近通话**：
  - 拨号键盘与常用功能；
  - CallKit 前台来电界面与全屏横幅接听/挂断；
  - 最近通话记录批量选择与删除。
- **离线号码归属地**：
  - 100% 离线识别国内手机号运营商（移动/联通/电信/广电）、省市归属、座机区号、服务号（银行/运营商/快递）、400/800 免费号；
  - 绝不联网查询，保护隐私。

## 2. 阶段边界与安全说明 (重要)

> [!IMPORTANT]
> **第一阶段运行边界**：
> 1. **局域网依赖**：iPhone 与 Mac 需处于同一 Wi-Fi 或局域网。
> 2. **前台运行**：本阶段尚未部署公网 APNs (Apple Push Notification service) 与 VoIP 推送；iPhone App 需保持前台以维持实时连接。
> 3. **Mac 唤醒**：Mac 需保持运行并打开 EC20Companion，网关默认处于关闭状态，需在 Mac 端系统设置中手动开启。
> 4. **证书边界**：采用 Curve25519 ECDH + ChaChaPoly 协议层端到端加密，第一阶段未预置企业/系统级 TLS CA 根证书，请勿在不受信任的公共 Wi-Fi 中开启。
> 5. **音频说明**：当前阶段完成信令控制（接听/挂断/拨号），语音 PCM 远程网络流将在下一阶段提供。

## 3. 生成工程与运行步骤

由于当前构建环境为无 Xcode GUI 的 CommandLineTools，iOS 工程采用声明式工具 **XcodeGen** 配置。在拥有完整 Xcode 的 Mac 上执行以下步骤：

### 步骤 1：安装 XcodeGen
```bash
brew install xcodegen
```

### 步骤 2：生成 Xcode 工程
在仓库的 `iOS/` 目录下执行：
```bash
cd iOS
xcodegen generate
```
执行后将在 `iOS/` 目录下生成 `EC20Mobile.xcodeproj`。

### 步骤 3：在 Xcode 中打开并配置签名
1. 双击打开 `EC20Mobile.xcodeproj`；
2. 在项目设置中的 **Signing & Capabilities** 页面：
   - 勾选 **Automatically manage signing**；
   - 选择您的 Apple 开发者账号 Team；
   - 根据需要修改 Bundle Identifier。
3. 连接 iPhone 真机（iOS 16+），并在手机上打开“开发者模式”。

### 步骤 4：构建与运行
1. 选择您的真机作为运行目标设备；
2. 点击 **Run** (Command + R) 编译并安装到 iPhone；
3. 首次启动时，系统将弹出请求 **本地网络访问权限**，请务必点击 **允许**。

### 步骤 5：配对与使用
1. 在 Mac 端 EC20Companion 中，进入 **系统设置与高级管理 ➔ iPhone 局域网互联**；
2. 开启网关开关，并记下界面上显示的 **16 位安全配对密钥**；
3. 在 iPhone App 中输入该配对码并点击 **立即验证配对**；
4. 配对成功后可尝试短信、电话信令和通讯录同步。电话音频传输尚未实现；请先用自己的号码做小范围验证。
